# Open Design Adaptation Notes

Open Design is useful as design intelligence, not as ReFusion execution.

## Take From Open Design

- skill folder discipline;
- prompt workflows;
- design brief structure;
- craft rules;
- anti-AI-slop checks;
- critique rubrics;
- visual hierarchy thinking;
- template thinking as scene recipes;
- layout-before-animation principle.

## Do Not Take From Open Design

- HTML output as source of truth;
- CSS animations;
- JS/GSAP timelines;
- web page templates as final artifacts;
- iframe/artifact preview as ReFusion output;
- media generation commands as scene execution;
- generic website layout rhythm when a video scene is needed.

## Translation Table

| Open Design concept | ReFusion-native equivalent |
|---|---|
| page | composition/canvas |
| section | beat or scene region |
| div/card | shape/text/image/video layer |
| CSS tokens | ReFusion design tokens |
| CSS animation | channels/keyframes/SpeedyGraph |
| HTML artifact | DirectorPlan + SceneProgram JSON |
| critique report | DirectorPlan/SceneProgram QA |
| template | motion recipe |
| design system | ReFusion design token pack |

## Main Rule

Use Open Design to improve taste. Use ReFusion contracts to produce the scene.
